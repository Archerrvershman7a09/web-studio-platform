# Состояние платформы

## Проверка исходного экспорта

Экспорт из Replit содержит React/Vite-приложение с навигацией и библиотекой UI.
Все 13 целевых страниц (главная, работы, три демо, конструктор, оценка,
референсы, кабинет, вход, готовность и админка) были заглушками с названием.
API содержит только проверку состояния; схема проектов и авторизация отсутствуют.
Заявленные в сообщениях Replit возможности не подтверждены исходниками.

## Первая доработка: независимая основа

- Удалены импорт и выполнение Replit banner/cartographer/runtime-overlay из основного сайта.
- Убрана фраза built on Replit из SEO/Open Graph/Twitter description.
- PORT и BASE_PATH необязательны, стандартная сборка работает отдельно от редактора.
- Конфигурация Vercel собирает только основное приложение и обслуживает SPA-маршруты.
- Главная: предложение, интерактивное переключение визуальных эскизов, процесс,
  объяснение стоимости, пустое состояние отзывов, FAQ. Контент RU/KA/EN.
- Добавлены три отдельные демонстрации: меню с фильтром и демо-бронь кафе; услуги/выбор специалиста/демо-запись салона; мебельный каталог, материалы, корзина с суммой и удалением. Иллюстрации CSS, без реальных операций.
- Работы ведут в демонстрации. «Хочу похожее» сохраняет референс в черновике и открывает конструктор.
- Конструктор: шесть шагов, параметры из задания, несколько референсов, localStorage и экспорт JSON. Нет отправки серверу.
- Кабинет, вход, расчёт цены и админка честно сообщают о недоступности.
- Мобильная навигация, focus-visible, уменьшение анимации, масштабирование,
  обновление HTML lang, устойчивость к блокировке localStorage.
- До готовности публичного запуска отключена индексация (HTML и HTTP заголовок).

Название Tbilisi Web Studio — временное название из экспорта, требует подтверждения.
Грузинские и английские тексты требуют редакторской проверки перед коммерческим запуском.
Техническая информация в истории Git не удаляется; видимая реклама инструментов не нужна.
Конфигурация других экспериментальных приложений сохранена, они не входят в целевую сборку.
